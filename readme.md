# shadow

一个粉丝向的编程语言表达作品，为 B 站 UP 主 [李豆沙](https://space.bilibili.com/1703797642) 制作。

> 本项目与任何官方机构无关，纯属粉丝自发创作，仅供学习与交流使用。

## 关于

shadow 是一个具备自举能力的编程语言及其编译器实现（当前为 0.5.3 版本）。
本仓库聚焦于语言本身的实现与配套工具链。

## 目录速览

- `src/`：shadow 编译器源码（以 shadow 语言自身编写）
- `rt/`：运行时（C）
- `build/shadow.exe`：自举 HOST，由 0.5.3 每轮自举 [5/7]（file_copy stage2 → build/shadow.exe）留下，作下一轮自举的编译器；已入库（CI 冷启动用）。运行时 C 源在 `rt/`。
- `std/`：标准库
- `pkg/`：打包与安装相关
- `test/`：测试用例与回归运行器

## 构建与运行

具体构建与运行方式见仓库内相关脚本与文档。
